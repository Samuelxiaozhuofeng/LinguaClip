# BRIEF · LinguaClip 播客精听宣传片（B 站）

按 motion-video-kit（business-motion-film）流程做。不参考以前的 LinguaClip 宣传片。

- **产品**：LinguaClip，Mac / Windows 桌面 App，开源。功能「播客」：导入一集播客 → 在电脑上生成文字稿 → 按段「精听」四步：1 盲听 · 2 对稿 · 3 再盲听 · 4 听写。
- **观众**：B 站上学外语的人（英 / 日为主）。他们已经在听播客，但听完就忘、听不懂的地方滑过去了。
- **观众的问题**：听了很多，但「没听懂就过去了」，提升慢。
- **唯一行动（CTA）**：去 linguaclipapp.com 免费下载。
- **能证明为真的**（以 `docs/private/podcast.md`、`utils/i18n.zh.ts`、`pro/podcastShows.ts` 为准）：
  - 推荐节目 6 种语言（英 日 西 法 德 韩），23 个节目，每种语言入门 / 中级 / 高级三档。
  - 也能粘贴 Apple Podcasts 链接或 RSS 地址。
  - 导入 = 下载这一集，在你电脑上生成文字稿（也可选云端转录）。
  - 一集自动切成几分钟一段；每段四步；第 1 步后问「盲听时听懂了多少？大部分 / 一半左右 / 很少」。
  - 盲听时按 S 做记号；V 只看这一句；对稿时点词查释义、☆ 收藏句子；收藏句拿去听写。
  - 顶栏显示语速「每分钟 N 词 · 偏慢 / 适中 / 偏快」。
  - 连着两次「很少」→「这个节目对你可能偏难」+ 推荐低一级节目。
  - 卡片写「精听到第 N 段 / 共 M 段」。
  - 目前所有功能免费。
- **绝不声称**：提分、多少天听懂、用户数量、评价；不出现播客台的 logo（只写节目名文字）。片中示例句子是自写的演示文本，不是任何节目的真实转录。
- **素材**：没有现成素材。App 界面用 HTML 按真界面重绘（同样的颜色、字体、文案）；开场一张 AI 生成的氛围图。片尾标「界面为示意重绘 · 部分画面由 AI 生成」。
- **品牌**：底 paper `#FAFAFA`，白面板 `#FFFFFF`，填充 `#F4F4F3`，线 `#E7E5E4`，次要字 `#78716C`，主字 ink `#1C1917`，唯一主色朱红 `#E8492B`（浅 `#FDECE8`）。字体 Instrument Sans + PingFang SC；学习的句子用 Source Serif 4。App 图标：横线本子纸 + 墨绿播放三角 + 黄色高亮条。
- **规格**：60 秒，16:9，1920×1080，60fps，带配乐和音效、无旁白，静音也能看懂；中文大字。
- **完成标准**：`references/quality-bar.md`（冻结时间 ≤ 2s / 60s，单段不动 ≤ 0.6s 除片尾；响度 −16 LUFS 左右、峰值 ≤ −1 dBFS；无文字碰撞；首帧即完整画面；静音看完能说出「这是干什么的、去哪下」）。
